КОМНАТА УРОКА: доска Holst + видео на одной странице
=====================================================
Нужны 2 бесплатные регистрации: GitHub (хранит файлы) и Render (запускает сайт).

ШАГ 1. GitHub
1. Зайди на github.com и зарегистрируйся (или войди).
2. Нажми "+" вверху справа -> New repository.
3. Название: lesson-room. Выбери Public. Нажми Create repository.
4. На странице нового репозитория нажми ссылку "uploading an existing file".
5. Перетащи в окно ВСЕ файлы и папку из распакованного архива:
   server.js, package.json, render.yaml и папку public (с файлом index.html внутри).
   Папку node_modules не загружай, её нет.
6. Внизу нажми Commit changes.

ШАГ 2. Render
1. Зайди на render.com, выбери вход через GitHub.
2. New + -> Web Service -> выбери репозиторий lesson-room.
3. Если поля уже заполнены из render.yaml, оставь как есть. Иначе:
   Runtime: Node, Build Command: npm install, Start Command: npm start, Instance Type: Free.
4. Нажми Create Web Service и подожди 2-5 минут, пока статус станет Live.
5. Вверху будет адрес вида https://lesson-room-xxxx.onrender.com. Открой его.

ШАГ 3. Урок
1. Открой этот адрес, вставь код доски (Holst: Поделиться -> Встроить), нажми создать ссылку.
2. Отправь ссылку ученице. Больше ничего не нужно, видео в самой странице.

ВАЖНО
- На бесплатном тарифе Render сайт засыпает, если им никто не пользуется. Первое открытие может грузиться до минуты. Открой ссылку за 2-3 минуты до урока.
- Камера и микрофон работают только по https, а Render его даёт сам.
- Если видео не соединяется (в строке состояния канал не становится connected), пришли мне скрин.
